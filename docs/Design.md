# Visual & UI Design System

## 1. Aesthetic Direction
A modern, dark-mode dashboard tailored for high legibility, clean status tracking, and rapid manual resolution of pending applications.

## 2. Color Palette
- **Background**: `#0f172a` (Slate 900)
- **Card / Surface**: `#1e293b` (Slate 800)
- **Border**: `#334155` (Slate 700)
- **Primary Text**: `#f8fafc` (Slate 50)
- **Secondary Text**: `#94a3b8` (Slate 400)
- **Accent / Action**: `#3b82f6` (Blue 500)

### Status Badge Palette
- **APPLIED**: `#10b981` (Emerald 500)
- **PENDING**: `#f59e0b` (Amber 500)
- **FAILED**: `#ef4444` (Rose 500)
- **SCORED / QUEUED**: `#6366f1` (Indigo 500)

## 3. Typography
- **Font Family**: `Inter, system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif`
- **Headings**: Semibold (600), clean spacing.
- **Data / Metrics**: Monospace (`ui-monospace, SFMono-Regular, Menlo, Monaco, Consolas, monospace`) for IDs, scores, and job URLs.

## 4. UI Layout
- **Header**: App title, total applications, daily limit meter.
- **Metrics Bar**: 4 stat cards (Applied, Pending, Failed, Total).
- **Applications Table**: Job Title, Company, Score, Status badge, Date, Action buttons.
